# **App Name**: MediSync AI

## Core Features:

- Mock Healthcare Data Generation: Programmatically generate realistic mock healthcare datasets (patients, conditions, medications, etc.) using pandas DataFrames directly within the code, simulating various fragmented sources.
- ABHA_ID Authentication Simulation: Simulate patient search and authentication by accepting an ABHA_ID input to access and process mock patient records.
- Fragmented Data Integration: Retrieve and integrate disparate patient records from the simulated fragmented data sources (pandas DataFrames) based on the provided ABHA_ID.
- Centralized Patient Report Generation: Compile and merge all integrated patient data into a comprehensive, structured centralized healthcare report presented in a doctor-friendly format.
- AI Medical Summary Generation: Analyze integrated patient conditions, allergies, medications, abnormal observations, and procedures using a summarization tool to generate a concise, doctor-friendly clinical summary.
- Modern Healthcare Dashboard UI: Display the centralized patient report, AI medical summary, patient profile, and other alerts within a modern, clean, and intuitive healthcare dashboard user interface.
- Responsive Layout: Implement a responsive design for the dashboard, ensuring optimal viewing and interaction across various screen sizes and devices.

## Style Guidelines:

- Primary color: A calm, professional blue (#4DBBE3) to signify trust and clarity in a healthcare context. The primary color provides strong contrast against lighter elements, guiding attention without being overly bold.
- Background color: A very light, desaturated cool grey (#F2F6F7) to create a clean, minimalist, and serene hospital-like environment, promoting readability and focus on content.
- Accent color: A subtle yet distinct teal-cyan (#22B9B2) for interactive elements, highlights, and critical information. This analogous color provides a refreshing touch while maintaining the overall professional aesthetic.
- Headline and Body Font: 'Inter' (sans-serif) for its modern, objective, and highly readable characteristics, suitable for conveying critical medical information clearly and efficiently.
- Utilize a consistent set of crisp, professional medical-themed line icons for navigation, patient alerts, data categories, and functional elements, maintaining a clean and modern appearance.
- Implement a modular dashboard layout featuring a left-aligned sidebar navigation, clearly defined content sections for patient details, report, summary, and alerts, utilizing soft shadows and modern card-style components for visual separation.
- Incorporate subtle and smooth transition animations for sidebar expansion/collapse, content loading, and card interactions to enhance user engagement and provide a fluid navigational experience without distraction.
